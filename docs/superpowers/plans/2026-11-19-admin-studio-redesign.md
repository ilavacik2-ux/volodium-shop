# План реализации: Редизайн и модернизация админ-студии VOLODIUM PARFUM

> **Для агентов-исполнителей:** ОБЯЗАТЕЛЬНЫЙ ПОД-НАВЫК: Используйте superpowers:executing-plans (или subagent-driven-development) для пошагового выполнения плана. Отслеживайте шаги с помощью чекбоксов (`- [ ]`).

**Цель:** Превратить админ-панель `admin.html` в сверх-удобную, практичную и надежную студию управления (All-in-One Studio), полностью синхронизированную с актуальным сайтом [volodium-shop](https://ilavacik2-ux.github.io/volodium-shop/), с исправлением всех битых картинок, автономным сохранением на GitHub Pages и удобным экспортом `perfumes.js`.

**Архитектура:** Единый веб-интерфейс студии на чистом JavaScript/CSS без внешних тяжелых зависимостей. Двухуровневое хранилище (локальный `localStorage` на GitHub Pages + опциональный REST API Python-сервера) с мгновенной кросс-вкладочной синхронизацией через `BroadcastChannel('volodium_sync')`. Универсальный резолвер медиа-путей, исключающий появление ошибок 404 и битых иконок `[?]` в Safari.

**Стек технологий:** HTML5, CSS3 (Luxury Bordo & Noir Palette, CSS Grid/Flexbox), Vanilla JavaScript (ES6+, BroadcastChannel, Blob Download API, LocalStorage).

**Спецификация:** `docs/superpowers/specs/2026-11-19-admin-studio-redesign.md`

## Глобальные ограничения
- Никаких абсолютных путей с ведущим `/` для локальных ассетов (чтобы не ломать GitHub Pages в папке `/volodium-shop/`).
- Полное сохранение обратной совместимости с существующими структурами данных `PERFUMES_DATA`, `AROMA_BOXES_DATA`, `SECRET_BOXES_DATA` и `VOLODIUM_SITE_CONTENT`.
- Никаких внешних тяжелых фреймворков; мгновенная загрузка в любом браузере (Safari macOS/iOS, Chrome, Firefox).

## Фокус проверки (Review Focus)
1. **Разрешение путей изображений на GitHub Pages**: проверка, что `assets/img/aromaboxes/...` и `assets/images/...` открываются без знака вопроса `[?]`.
2. **Отказоустойчивость сохранения без бэкенда**: сохранение боксов, отзывов, текстов и промокодов должно сохраняться в `localStorage` и не выдавать ошибку API.
3. **Корректность генерации `perfumes.js`**: скачиваемый файл должен быть валидным JS-файлом с объявлением всех 4 глобальных переменных.
4. **Отображение Hero в точности как на сайте**: заголовок «Соберем твой парфюмерный гардероб» с тонкой и жирной строками.
5. **Ссылки на витрину**: клик по «Витрина» открывает `index.html`, а не корень `/`.
